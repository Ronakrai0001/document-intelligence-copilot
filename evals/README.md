# Retrieval smoke checks

Upload [`../samples/sample-handbook.md`](../samples/sample-handbook.md), then ask these questions with AI drafting off. Confirm the matching excerpt appears and is traceable to the filename and passage number.

| Question | Expected evidence |
| --- | --- |
| How long do I have to submit a travel reimbursement request? | Submit within 30 calendar days after the trip ends. |
| What receipts and approval do I need for expenses? | Itemized receipt and manager approval. |
| What is the daily meal limit during overnight travel? | 45 USD per day; exclusions are in the same section. |
| How early should I request more than three days of leave? | At least two weeks ahead. |
| How soon do I report a lost laptop? | As soon as possible and no later than one hour after discovery. |
| Can confidential customer files go into personal cloud storage? | No. |

This is a human-readable smoke set, not a scored benchmark. It checks obvious retrieval coverage, not answer quality across varied document sets.
