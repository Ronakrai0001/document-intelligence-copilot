# Security policy

This project is an early-stage, single-user local application. Do not use it as an internet-facing upload service or with documents you are not authorized to process.

## Reporting a vulnerability

If GitHub's private vulnerability reporting is enabled for this repository, use **Report a vulnerability** to disclose security issues privately. Otherwise, contact the owner through their GitHub profile. Do not publish exploit details in a public issue. Include the affected version/commit, impact, and a minimal reproduction where possible.

There is no guaranteed response time or production support commitment for this portfolio project.
